# I am biker update history.

## Version 1.0.0 BETA
This vas the first version of the project that had microservice structure with jwt
authentication and database connectivity.

## Version 1.1.0 BETA
In the second beta version of project main goal was to refactor project to make future
development easy. Refactoring included: changing package names to conventional, using
conventional packages structure and rewriting rest api controllers to always return
value using ReponseEntity instead of text or pure objects.

## Version 2.0.0 Stable
This is first stable version with dockerfiles which is tested and has good logging. Also
a new microservice called forum-service has been added to create simple forum
for users to write posts.
